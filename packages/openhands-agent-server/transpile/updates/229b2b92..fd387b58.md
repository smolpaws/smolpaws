## Behavior and evidence

Active-profile reads repair a missing/dangling selection using a seed or valid fallback, preserve unreadable entries and respect the 50-profile cap. Deleting the active profile reselects without changing the active LLM profile. Generic conversation creation retains explicit profile/settings precedence. SDK launch additions preserve independent roles, public-only skill selection, denylist, immutable context and provenance. One catalog service owns HTTP discovery and profile launch snapshots; bare settings do not load an unused profile catalog.

Skills sync now performs a real strict repository fetch and preserves both caches on failure. Marketplace data caches only nonempty results for 300 seconds, with live installed flags. Local install/refresh stages complete resources and replaces atomically, rejects escaping/cyclic resources and preserves enabled state. Unsupported remote install and org/registered marketplace loading remain explicit errors without a host adapter. Read-only subagent discovery never registers or executes a child. Browser metadata and runtime availability have distinct source-defined predicates.

Boundary tests cover rejected secret overwrites before mutation, accepted whitespace preservation, file upload 400 responses for directories/parent files, empty session keys, disconnected refresh errors, supported model discovery and canonical browser registration. Focused tests were observed red before their corresponding fixes; independent review also corrected canonical browser naming and provider model filtering.
